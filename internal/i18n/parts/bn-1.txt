# tippani — বাংলা. The other half of this pair is en.txt beside it.
#
# The format is en.txt's format, and en.txt is the source of truth for both
# sides: same keys, same order, same section banners. A comment above a key is
# the context copied down from en.txt for whoever writes the Bengali; it is not
# translated, because it is a note to the writer and not a string on screen.
#
# AN EMPTY VALUE COUNTS AS ABSENT and the resolver falls through to English, so
# a key nobody has reached yet costs coverage and nothing else.
#
# TWO TEMPORARY MARKERS live in this file, both as comments ABOVE a key, never
# inside a value — the parser ships everything after the first = to the screen:
#
#   # ?? …   the writer is not sure of this line
#   # !! …   this line is too long for its cap or its control
#
#   grep -n '^# [?!][?!]' internal/i18n/bn.txt

# Read quotes aloud (issue #12, "Audio review, in the browser only")

Not built. Tasks, one per ask:

- [ ] Read a quote aloud with the browser's own speech (Web Speech API, `speechSynthesis`), with no service and no download.
- [ ] A play/stop control on every quote card and on a quote's detail, drawn with the app's own glyph.
- [ ] Speak in the quote's own language, from its language tag, falling back to the interface language.
- [ ] Let the reader choose a voice per language from the voices the device has, stored with their preferences.
- [ ] Read a whole anthology or board in order, with next and stop.
- [ ] Hide the control where the browser has no speech voices, instead of showing a button that does nothing.
